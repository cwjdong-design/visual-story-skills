# 03 · 分镜总纲与逐镜细化

读取当前故事和制作设定。事件与因果遵循故事，造型与状态遵循制作设定；两者冲突时报告，不发明折中版本。短剧同时读取 short-drama.md。

## 先总纲，后细化

1. 列出结局成立不可少的事实、行动、证据、回应与状态变化。
2. 先为后段行动和结尾兑现预留容量，再安排导入、触发、过渡与情绪停顿。不按原文段落长度或固定百分比分镜。
3. 每格/镜写清叙事作用 beat、当前画面 instant、原文逐字依据、使用的资产和状态、进入/离开状态、时间联系与必须传达的信息。
4. 检查数量/时长和信息容量后再细化景别、构图、表演和文字。用户已确认的总纲不能在细化批次中悄悄重新分配剧情。

大项目按页/场/镜头批次细化，只携带本批相关原文、冻结总纲切片、相关资产、上一相关状态和邻接镜头。不能仅带最近三镜而忘记更早出现的关键道具状态；也不把整项目聊天反复拼入上下文。

## 漫画：一格一个瞬间

“挑选照片→取消→发文字→等回复”不是一个画面。选择其中一个可同时成立的动作和物件状态，前后过程另分格或用容量内的必要文字交代。after 是衔接约束，不把未来行动提前画入 instant。

每格相较前格应增加信息、选择、行动或结果。没有新增作用的连续凝视、等待可以合并信息、释放格位；不是把几个时点硬塞进一格。允许有意义的停顿，不以停顿挤掉关键因果。

## 选择而非重写设定

现场可见对象引用已有 asset/look/state；文字人物可以在 assetIds 中，但不能进入 visualTargets。不要为动作方便擅加包、首饰或新工具。缺少必要资料时，标记镜头并返回制作设定修订。

选择状态前读懂含义：看不见容器内物品不等于物品已取出；首次出场不等于常态；离场不等于复原。检查前次离场 → 本镜 before → 当前状态 → after。画内人物沿道具绑定继承，不变成现场人物。

## 时间与文字

- “数月后”“另一晚”“持续聊天”等跨度不能为了同页方便压成一次行动。原文模糊就保持模糊，不造精确日期。
- 不把重要事实只藏在 sourceQuote、描述或审核备注里；观众必须能从画面和实际可见/可听文字获得它。
- 对策略或指导保留可执行方法与限制，并安排实施后的承接，不只写“获得建议”。不同人的关键问答不要合成无归属旁白。
- 每条可读文字只安排一个呈现位置。屏幕文字和气泡不要重复抄同一句；画外来信不画成现场人物开口，旁白不变成角色对白。
- 漫画文字容量是可配置制作约束，不是跨项目定律。缺少用户标准时可提出三格页每格约45字、整页约120字、单格约70字作为初始建议，标点计入；实际以画幅、字号和可读性调整。不能用极小屏幕长文逃避容量。

## 交付与检查

写 `shots.json`，保留稳定镜头 ID、引用的故事/设定版本和未解决警告。核对每条关键因果具体落在哪一镜，逐镜读文字、走状态链。数量装不下时明确遗漏及影响，提出减内容或增容量的选择，不代替用户声称已经完整。
