# 05 · 审核、返工与接续

## 分三层审核

1. **结构与依据**：版本、资产/造型/状态引用、原文引文、镜头数量/时长。可用离线脚本辅助。
2. **叙事与连续性**：关键因果是否可见、信息揭晓时点、对白归属、服装/道具状态、出入画和时间跨度。
3. **真实媒体**：实际打开生成图片/视频，检查身份、手部和关键物件、可读文字、画面衔接与声音。无法查看媒体时明确这一层未检查，不以提示词代替实际验收。

问题记录：对象或镜头 → 可观察问题 → 对应依据 → 严重程度 → 最小修改 → 受影响范围。事实错误和可选审美建议分开；不伪造评分或把无问题当成无需人工确认。

## 局部返工

- 故事事件变化：检查制作阶段/状态、相关镜头、参考与生成结果。
- 人物造型变化：检查引用该造型的镜头与参考，不重做无关场景。
- 单镜构图或文字变化：优先只改该镜；如改变动作落点，再查相邻衔接。
- 仅生成质量失败：保留故事与镜头版本，新增生成尝试，不重写剧情。

覆盖前保留受影响产物的历史副本和修改原因。递增被修改文件的版本；下游依赖仍指向旧版本时标记 stale。旧素材不能因改了文件名自动成为新镜头的合格结果。镜头通过后，采用结果的记录包含对应镜头版本、真实任务 ID 或本地结果及审核依据。

## 交接和停止

更新 `progress.md`：当前阶段、有效版本、已采用/待审内容、已执行的真实操作、阻塞、授权剩余范围、下一步。未知任务保留定位信息，不能为了继续流程改成失败或成功。

新 Agent 先读取项目索引、进度、相关版本和任务记录；核对后接续。不要因为缺少旧聊天就重建身份或重新提交生成。没有可用平台工具、生成授权耗尽、事实冲突未决或当前任务结果未知时，在对应边界停止并说明需要什么。

最终交付区分：方案完成 / 素材生成完成 / 媒体审核完成 / 剪辑完成 / 发布完成。没有对应证据的阶段不得勾选。
