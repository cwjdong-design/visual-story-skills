# 方法提取与验证边界

本仓库经项目所有者要求，从其既有漫画制作流程中重新整理通用方法。没有复制应用源码、内部接口、用户记录、数据库、生产素材或模型凭证，也不需要访问原项目。

| 原流程方法 | 独立版本 |
| --- | --- |
| 故事诊断：完整性、因果、共鸣、结尾与改动披露 | 01-story.md，保留不强加反转和推广目标的边界 |
| 制作统筹：身份/造型/状态、事实/设计、时间与画内人物 | 02-production.md，改为本地文件与稳定 ID |
| 分镜：全篇总纲后逐批细化、单时点、文字容量、状态链 | 03-storyboard.md，去掉服务端冻结和数据库投影要求 |
| 参考图用途与成图约束 | 04-production-tools.md，改为实际工具能力发现与制作意图 |
| 确认、版本、调用证据与恢复 | 文件状态、历史版本和 runs.json；用户授权仍来自真实委托 |

原来由应用代码维护的规则，分成 Agent 指令、模板和必要的本地检查。未照搬原输出 schema：数据库 ID、服务端来源清单和特定模型输出协议不是通用技能的前提。

## 新增而非已提取验证的部分

短剧镜头时长、声音、首尾帧与剪辑是扩展规则；视频工具执行以用户实际能力为准。本版不附带商业平台专用适配器，不声称已产出真实成片。

## 本版验收方式

- Skill 文件结构、相对引用和公开包内容检查。
- 原创漫画/短剧规划示例的离线检查。
- 损坏输入、过期版本、引用、状态、时长和任务恢复的回归测试。
- 可重复构建仅含技能及必要许可证说明的分享包。

以上不是独立 Agent 行为测试，也不是真实图像/视频质量评审。后续只有在获得工具与执行授权后，才补充可复现的真实兼容记录。
